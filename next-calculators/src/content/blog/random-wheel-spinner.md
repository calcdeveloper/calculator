## How does the Tool work? (The Algorithm)

While the wheel *looks* like a physical object obeying the laws of friction and gravity, it is actually a highly sophisticated piece of front-end web engineering. How does a computer simulate the slowing down of a physical wheel?

Here is a look at the fascinating computer science and geometry used behind the scenes:

### 1. The Core RNG Engine
At the absolute core of the wheel is a standard PRNG (Pseudo-Random Number Generator). Before the wheel even starts visually spinning on your screen, the algorithm has already mathematically determined the winner. It instantly generates a random number representing an exact degree on a 360-degree circle (e.g., it decides the pointer will stop at exactly 142.5 degrees).

### 2. Mapping Choices to Degrees
The software looks at how many options you typed in. If you typed in 4 options (Pizza, Sushi, Tacos, Burgers), the software divides 360 degrees by 4. It assigns a 90-degree wedge to each option. It then checks which option occupies the 142.5-degree mark (which the RNG selected) to determine the winning slice.

### 3. CSS and JavaScript Animation (Easing)
This is where the magic happens. The algorithm knows the wheel needs to end up at 142.5 degrees. It then programs a visual animation for the wheel to spin multiple full rotations (e.g., spinning 10 full times plus the final 142.5 degrees). To make it look realistic, the code uses an animation property called "Ease-Out." This forces the spin to start incredibly fast, and then gradually decelerate over 5 or 6 seconds, mimicking the physical friction of a real wheel slowing down until it perfectly hits the predetermined mathematical angle.
