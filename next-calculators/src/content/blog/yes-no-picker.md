## How does the Tool work? (The Algorithm)

It might seem like a simple magic trick, but generating a mathematically pure, perfectly unbiased 50/50 split is actually a serious computational process. How does a computer code ensure that "Yes" and "No" have the exact same probability of appearing?

Here is a look at the fascinating computer science used behind the scenes to generate your binary fate:

### 1. The Boolean Foundation
In computer science, the absolute core of all programming is built on binary logic, known as Booleans. A Boolean is a data type that only has two possible values: **True (1)** or **False (0)**. The Yes or No Picker is essentially the purest, most fundamental expression of computer programming. The code assigns "Yes" to the value of 1, and "No" to the value of 0.

### 2. The PRNG Engine
When you click the button, the tool activates a Pseudo-Random Number Generator (PRNG). The algorithm grabs a tiny, chaotic variable from your computer's system (usually the exact current millisecond on the clock, like 432). 

### 3. The Modulo 2 Operation
Once the PRNG generates a massive, random internal number, the algorithm applies a mathematical operation called "Modulo 2." This operation divides the random number by 2 and asks for the remainder. 
*   If the random number is even, the remainder is exactly 0 (which translates to **No**).
*   If the random number is odd, the remainder is exactly 1 (which translates to **Yes**).

Because the computer clock is shifting thousands of times a second, it is physically impossible for a human to time their click to force an Even or Odd outcome. The result is instant, mathematically flawless, and perfectly balanced at a 50% probability for either outcome.
