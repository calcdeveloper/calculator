## How does the Calculator work? (The Algorithm)

Because the calculator is built exclusively for entertainment and not for sociological research, it does not actually monitor how often you text your friend or how many times you have helped them move a couch. However, the software relies on genuine, consistent mathematical string-matching algorithms. This means that if you type the exact same two names tomorrow, you will get the exact same percentage.

Here is a look at the common digital algorithms used behind the scenes to calculate your friendship fate:

### 1. The F-R-I-E-N-D-S Letter Matching Method
This is a classic algorithm adapted from pen-and-paper games. The system analyzes both names and specifically counts how many times the letters from the word **F-R-I-E-N-D-S** (and sometimes **B-F-F**) appear.
*   *Example:* If the names are "Rachel" and "Monica", the algorithm counts the R's, E's, N's, etc.
*   It takes those counts, aligns them into a string of integers, and mathematically adds adjacent numbers together in a recursive loop until it is crushed down into a final two-digit percentage.

### 2. The ASCII Character Value System
Every single letter you type on a keyboard has a hidden, underlying numerical value in computer science (known as the ASCII code). For example, a capital 'M' is mathematically different from a lowercase 'm'.
*   The calculator breaks down both names into their absolute numerical codes.
*   It adds up all the values for Friend A, and all the values for Friend B.
*   It then processes these massive sums through a specialized mathematical formula (usually involving a modulo operation) to generate a pseudo-random, yet completely mathematically consistent, percentage between 1 and 100.

### 3. The Vowel-to-Consonant Harmony Algorithm
Some highly modern calculators analyze the phonetic rhythm of the names. They compare the number of vowels to the number of consonants in both names to determine "name harmony." If the names have a mathematically complementary ratio, the algorithm boosts the Friendship Percentage significantly higher.

Regardless of which specific mathematical engine is running, the final result is always instantaneous, perfectly consistent, and completely unique to the exact combination of letters you typed.
